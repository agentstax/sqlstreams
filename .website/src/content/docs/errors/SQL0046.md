Delivery rows written `'deferred'` because another delivery held their
message key; they re-enter through the exception window when the key
frees.

A session flow: this instance's own running total, flushed to
`__system.metrics` each flush tick and printed as `deferred_count` on the
[consumer stopped](/errors/SQL0041) line. It never reconciles against the
fleet-wide `sqlstreams.consumer.*` gauges.
