Streams whose evaluation or alert-result production failed during one run of
the named alert check.

The `alert` attribute identifies the check. Compare this with
[`sqlstreams.alert.check.streams_evaluated`](/errors/SS0075) from the same retained
run to see how much of that pass failed.
