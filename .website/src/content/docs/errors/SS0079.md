slug: errors/SS0079
kind: "metric"
consequence: "unitless gauge, one series per stream"
---

Whether the stream has received a keyed message that opted into compaction.

The `stream` attribute identifies the stream. `1` means the stream snapshot found
compaction state; `0` means it did not. This reports stream state, not how many
messages were compacted.
