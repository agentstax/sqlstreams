Workers with a nonzero instance target and no live instance, owned by the
topic or one of its consumer groups. The metrics collector produces the count
and the matching worker identities in one measurement.

For `orders`, the key is `vulkan.topic.workers.unclaimed|topic=orders`.
`Metadata.workers` contains each worker's name, owner, and target instances.
These details are retained JSON, not metric labels. A successful healthy
collection produces zero and an empty list; a failed read produces no sample.

The worker-liveness alert applies the shared [pending rules](/concepts/alert-history/)
to this history. Missing or stale evidence leaves an existing alert unchanged
and increments the failed-topic check count.
