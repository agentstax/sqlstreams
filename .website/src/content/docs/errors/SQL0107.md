---
title: "worker is suspended"
slug: errors/SQL0107
kind: "error"
recovery: "permanent"
consequence: "an unchanged retry cannot succeed; retry machinery stops immediately"
fix: "stop this execution; unsuspend the worker to allow a new claim"
---

The worker's target is zero. A running instance observes this during renewal,
cancels its work, and releases its claim. The manager treats suspension as a
normal stop. Use the stream's [maintenance handle](/reference/maintenance/)
to permit new work.
