# Security policy

Report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/allegedlyreliable/sqlstreams/security/advisories/new).
Keep vulnerability details out of public issues and pull requests.

Include the SQLStreams and PostgreSQL versions, reproduction steps or a small
proof of concept, and the impact you observed. Remove credentials and private
application data from examples and logs.

The maintainer aims to acknowledge reports within seven calendar days.
This is an acknowledgment target, not a resolution deadline.

## Supported releases

Security fixes target the latest stable SQLStreams release and are delivered
in a new release. Older releases have no promised backports; upgrade to
receive fixes. Stable means a release without a prerelease suffix, including
stable v0.x releases.

For ordinary bugs, use the public issue process in
[CONTRIBUTING.md](CONTRIBUTING.md).
